Существуют два способа усовершенствования метода декомпозиции ячеек,
позволяющие исправить эти недостатки. Первый из них состоит в том, что допускается
дальнейшее разделение смешанных ячеек, возможно, с использованием ячеек, вдвое

рекурсивно до тех пор, пока не будет найден путь, полностью проходящий по свободным
ячейкам. (Безусловно, этот метод может применяться, только если есть возможность
определить, является ли данная конкретная ячейка смешанной, а эта операция является
простой, только если границы пространства конфигураций определяются с помощью
относительно простых математических описаний.) Такой метод является полным, при
условии, что заданы ограничения на величину наименьшего прохода, через который
должен пройти искомый путь. Хотя при этом основная часть усилий, связанных с
